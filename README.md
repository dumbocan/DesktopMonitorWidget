# Desktop Monitor Widget

Windows desktop widget for monitoring CPU, memory, and other system metrics.

## Download

Download the Windows executable from the [v1.0.0 release](https://github.com/dumbocan/DesktopMonitorWidget/releases/tag/v1.0.0).

The executable is also versioned in this repository at `binaries/DesktopMonitorWidgetWpf.exe` using Git LFS.
